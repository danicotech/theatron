# VS 墨跡

真跡已經接上了。來源 `art/_src/vs-ink-source.png`（1672×940，黑墨白紙的水墨 VS）。

| 檔 | 是什麼 | 用在哪 |
|---|---|---|
| `art/_src/vs-ink-source.png` | 原圖，不動它 | 重轉的來源 |
| `art/vs-ink.png` | 裁出 VS、紙鍵成透明、墨上成骨白 | 第 3 格中間的標記、對立圖中間的 VS |
| `art/vs-plate.webp` | 整幅轉 WebP | 對立圖的背景質感 |

## 為什麼要先轉一手

頁面的底是暗的，真跡的底是亮的。在執行期把紙去掉這條路走不通：
`invert(1)` ＋ `mix-blend-mode:screen` 看起來可行，但 `.chapter-sticky` 是
`position:sticky`，**自成一個堆疊脈絡**，混色模式碰不到底下 `#stage` 那層場景，
結果是一塊黑方塊蓋在畫面上。所以透明度必須先寫進檔案裡。

## 重轉

```
python tools/vs-import.py art/_src/vs-ink-source.png \
  --cx .512 --cy .482 --half .175 --floor .74 --gamma .70 --feather .66
```

現用的就是這組參數。轉完會存一張 `shots/_vs-import.png` 預覽（壓在暗底上），先看過再上。

| 參數 | 現值 | 作用 |
|---|---|---|
| `--cx` `--cy` | `.512` `.482` | VS 在整幅裡的中心 |
| `--half` | `.175` | 方框半邊長，以全寬為單位。調大裁得鬆 |
| `--floor` | `.74` | 紙的門檻。亮度高於 1−floor 一律當紙。**調低會把山巒的淡墨也吃進來，四周就開始起霧** |
| `--gamma` | `.70` | <1 讓筆畫更實 |
| `--feather` | `.66` | 從框邊往內羽化。不做的話殘留的淡墨會沿著裁框連成一個看得見的方塊 |
| `--ink` | `#f1e9d8` | 墨在暗底上呈現的顏色 |

裁框有一個坑：整幅畫左半是暗的（竹與山），**暗 = 高不透明度**，
所以框的左緣一旦切進那半邊，轉出來四周就會有一圈灰霧。
`--cx` 要夠靠右，`--half` 要夠小，左緣才留在中間那塊亮紙上。

## 底圖為什麼是放大偏移的

`.vs-scrim` 用 `background-size:300% auto; background-position:14% 70%`。
不能整幅照放 —— 那張圖自己中間就有一個 VS，會跟前景那顆疊成兩個。
放大三倍偏到左下角，只取墨的質感、不取字。

## 換掉真跡

覆蓋 `art/_src/vs-ink-source.png`，重跑上面那行，必要時調 `--cx/--cy/--half`。
另外把新圖存成 `art/vs-plate.webp` 給對立圖當底。HTML 和 CSS 都不用動。

## 沒有檔案的時候

`ink-title.js` 的 `inkVS()` 會先掛一顆程序生成的（一筆圈 ＋ V 兩筆 ＋ S 一筆 ＋ 九顆墨點），
真跡載進來才替換掉。`tools/vs-plate.mjs` 可以把那顆算圖成同格式的佔位檔。
