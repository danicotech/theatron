# Slop 審查清單

產出任何畫面後、開 PR 前跑一遍。

**核心判準:tell 是「沒被指定的預設」,不是「被禁的顏色」。**
你有理由選過的紫色通過;隨手落到的紫色不通過。
所以每一條的問法都是:**這是我選的,還是我沒選?**

---

## 配色

- [ ] 有沒有出現 AI 紫 / 靛藍(violet、indigo 當主色)?
- [ ] 有沒有出現「暖奶油底 + 襯線標題 + 鼠尾草綠或陶土色」?
      這是 2026 年最快上升的 tell —— 前一波反 slop 建議自己造出來的「有品味的預設」。
      換一個預設不算解決,只是把時鐘重設。
- [ ] 有沒有漸層文字、漸層按鈕、漸層 hero 背景?
- [ ] 深色底 + 霓虹光暈?
- [ ] 有沒有出現 `tokens.md` 以外的 hex 值?

## 字體

- [ ] Inter、Geist、DM Sans、Roboto、Arial、Space Grotesk、Poppins、Montserrat?
- [ ] Instrument Serif、Fraunces、Playfair Display?
- [ ] 數字有沒有用 mono + `tabular-nums`?
- [ ] 字重是不是全部落在 400 / 600 兩個值?(沒有層次的訊號)

## 版面

- [ ] 是不是「hero + 三張功能卡 + CTA」的骨架?
- [ ] 卡片裡面有卡片,裡面又有卡片?
- [ ] 是不是用堆疊卡片假裝版面,而不是真的做版面?
- [ ] 什麼元素都圓角?(表格、賠率欄位、分隔線應該是直角)
- [ ] 像不像沒改過的 shadcn / Tailwind 預設樣貌?
- [ ] 有沒有沒有敘事目的的 carousel?
- [ ] 有沒有 `01 / 02 / 03` 編號,但內容其實不是序列?
      這個專案有真的序列(賽事階段),那裡用編號是對的。功能列表用就是裝飾。

## 裝飾

- [ ] 玻璃擬態 / 毛玻璃面板?
- [ ] 側邊 tab 式的強調色邊框?
- [ ] 沒有資料意義的 spark line?
- [ ] emoji 當 icon 或放在標題裡?
- [ ] 陰影堆疊出來的假層次?(這個專案用 1px 邊框)

## 動態

- [ ] 是不是所有東西都 fade-up + 0.6s stagger?
- [ ] 動畫有沒有服務於理解,還是只是「動一下」?
- [ ] 有沒有包 `prefers-reduced-motion`?

## 文案

- [ ] 開場清嗓:「其實…」「重點是…」「說白了…」
- [ ] 二元對比句型:「不是 X,是 Y」「看起來像 X,實際上是 Y」
- [ ] 戲劇性斷句:「三個字。就這樣。」
- [ ] **句長節奏一致** —— 每句都差不多長。這是 2026 存活最久的文案 tell,最難自己看出來,朗讀一遍最快抓到。
- [ ] 空泛動詞:探索、體驗、賦能、解鎖、打造
- [ ] 按鈕寫的是實際會發生的事嗎?(「送出注單」不是「確認」)
- [ ] 同一個動作從頭到尾用同一個詞嗎?

## 品質底線

- [ ] 手機 375px 寬沒有橫向捲動、沒有溢位
- [ ] 鍵盤 focus 看得見
- [ ] 對比度過 WCAG AA
- [ ] 載入中、空、錯誤三種狀態都設計過
