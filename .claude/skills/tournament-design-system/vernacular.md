# 主題語彙

設計新畫面時,靈感從**這個主題自己的世界**來,不要從「什麼風格流行」來。

這是這個網站能長得不像任何 SaaS 的唯一來源。

## 可以借用的實體

| 來源 | 可借用的視覺特徵 | 已用在哪 |
|---|---|---|
| **運彩投注站的紙本賠率單** | 密集的等寬數字、嚴格的行列對齊、細分隔線、直角欄位、印刷感的緊湊排版 | 賠率顯示、注單 |
| **電競轉播的記分板 / lower-third** | 斜切的邊角、選手名 + 數值的橫向配對、進行中的脈動紅點 | 比賽節點 |
| **票根 / 收據** | 齒孔虛線、撕線、單據標頭的全大寫小字 | 投注單 |
| **抽籤箱與號碼牌** | 籤位編號、逐一揭曉的節奏、名字落位 | 抽籤階段 |
| **格鬥遊戲角色選擇畫面** | 對峙的左右構圖、選定時的強調框 | 對戰組合 |
| **競技場記分燈板** | 極淡的垂直網格條紋、發光的字符 | 頁面背景 |

## 用法

**借的是結構與質感,不是主題樂園式的直譯。**

- ✅ 賠率欄位用等寬數字、右對齊、細線分隔 —— 借了賠率單的**資訊密度與對齊紀律**
- ❌ 把整個頁面做成一張泛黃的紙、加咖啡漬材質 —— 那是 cosplay

## 文案語彙

用這個世界的詞,不要用產品行銷的詞。

| 用 | 不要用 |
|---|---|
| 報名、抽籤、備戰、開賽、判定勝者 | 開始使用、探索、體驗 |
| 這場、這關、串關、賠率、派彩 | 產品、方案、解決方案 |
| 商店已關閉 | 功能暫時無法使用 |
| 還有 3 人未抽 | 流程進行中 |

**按鈕寫實際會發生的事**,不寫抽象動詞。「送出注單」不是「確認」。而且同一個動作從頭到尾用同一個詞 —— 按鈕寫「報名參賽」,成功提示就寫「報名完成」。

## 空狀態與錯誤

- 空狀態是**邀請動作**,不是道歉:「從賽程樹挑選手加進來」而不是「目前沒有資料」
- 錯誤說清楚發生什麼事、怎麼修:「代幣不足」而不是「操作失敗」
- 錯誤不道歉、不模糊
