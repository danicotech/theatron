## 場景與動態

- 初訪預設輕量 2D 圖像場景，不匯入 Three.js 場景、不建立 WebGL。使用者可由桌機「場景」或手機導覽「更多功能」選擇 3D，偏好保存在本機。
- 切換保留目前網址參數與章節，使用文件導覽釋放舊繪圖環境；減少動態偏好仍優先使用靜態展示。
- 3D 原本需要場景幾何、貼圖、著色器初始化並持續逐幀渲染，會增加載入及 GPU 負擔。選用後限制裝飾場景最多 30 次／秒繪製；背景分頁仍沿用暫停機制。本次未宣稱跨裝置 FPS 或耗電量改善百分比。
- 比武月亮縮為原本 65%，移到右上並隨寬高比調整，降低月海與環形山反差。
- 章名以完整筆順時間軸縮放至最多 1500ms，包含停筆、換字、起始延遲與標點；閱讀模式直接顯示完整標題。
- 場景與彈窗遮罩使用固定深色語意 token；載入／點燃文字使用獨立亮色 token，避免淺色主題的深色紙面文字滲入。名稱改為夜鴉。
