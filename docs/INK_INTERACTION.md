## 結構與動態

- `SiteChrome` 在每個路由掛載共用 `mountInkWave`，事件委派支援稍後出現的表單和彈窗。`Button` 明確提供 `data-ink-variant`。
- 一般按鈕、區塊連結與 summary 使用 G；正文行內連結、品牌、人物／含圖片的卡片保留既有呈現，避免實色遮住美術。可用 `data-ink-wave="off"` 排除特殊畫面。
- 原始內容、事件、表單與尺寸不重建。只加絕對定位的 inert／aria-hidden 裝飾層；複製文字清除 ID 與表單名稱，原生焦點圈保留。React 更新文字、停用、切頁、關窗與卸載時丟棄裝飾層。
- 2026-10-21 最終選定「長浪追湧」：右側先湧上，左側延後 0.20 秒，上升段 1.12 秒；沿用試映的平緩波幅與雙層浪緣。hover／鍵盤聚焦時六顆細泡持續循環，離開完成退墨後停止 RAF。填滿後只更新既有氣泡節點，不重建 SVG 圖片或文字。
- 滑鼠離開退墨，鍵盤聚焦保持；觸控 1000ms 後退墨，不把觸控 focus 當 hover。reduced-motion 即時填色，無氣泡與循環。頁面失焦、背景、換主題與改尺寸清除動畫。
- 不新增 WebGL、全頁濾鏡、外部素材或動畫套件。舊導覽位移與高亮遮罩停用，選單開關動態保留。
