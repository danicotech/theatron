## 視覺方向
短操作回饋 150–180ms，使用透明度、微量按壓；大場景維持已確認的墨水節奏。功能表單採告示式標題、細分隔線、兩欄內容加參賽摘要；手機單欄、單一文件捲動。欄位提供必填／選填、用途、鄰近錯誤，核對頁可回到指定段落修改。

## 初始盤點（實作前）
現有本機報名僅姓名、ID 和四個自由文字角色欄位；缺少聯絡、自評、經驗、出席時段與備註。下一步缺少欄位錯誤定位，資料層錯誤在頁面頂端；步驟切換無焦點管理。共用 Button 有 hover 和 busy，缺少按下回饋；雅集 raw buttons 無一致短動畫。首頁與備戰各有獨立 style，應從 lab 正本統一最小互動而非套全域 transform 影響人物。
