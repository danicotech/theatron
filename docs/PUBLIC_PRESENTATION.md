# 百業試鋒：對外畫面與管理工作台

此檔供 Codex 與維護者使用，不能把本文件的規劃、驗收或開發提示渲染到公開頁面。

## 訪客畫面

- `/home`：靜態活動首頁。主題「百業試鋒」，主句「不同程度，同場試鋒。」；主要動作「了解賽制」「提筆報名」。次要入口為比武、賽程、會員專區。
- 七章維持原場景與既有藝術。品牌回到活動首頁；導覽永遠單行。
- 報名：中央收卷，只在紙上寫「報名表」。點擊原地展卷，保留四步流程。
- 賽程未發布：只顯示「抽籤後公布完整賽程與選手名單。」不推銷試看流程、不出現管理入口。
- 比武：姓名、比分、對局狀態、觀局入口。選手資料只顯示公開配置，不展示自動產生的示範配裝。
- 備戰面板：兩列武器圖，必要名稱；心法縮圖；其餘配置收合。精確對應既有 catalog 名稱才能取圖，未知名稱僅顯示文字，不假配圖片。
- 會員：登入／註冊 → 個人總覽 → 報名與角色、注單、點數、兌換。匿名與模擬 Discord 不出現在訪客入口。
- 留下短而真實的體驗資料標示，避免將本機點數或樣本賽果說成正式資料。

## 管理模式

明確使用 `mode=manage` 進入管理檢視。首頁的階段試看、人物演出試看、墨韻研究、示範資料編輯與活動管理捷徑只在此模式顯示；觀局工作台的建賽、判勝、盤口設定亦同。一般頁面不提供模式切換或自動進入管理。

管理入口：`/sportsbook?mode=manage`；場景預覽：`/?mode=manage&preview=1#schedule`。

此處是本機展示模式隔離，不是正式管理員認證。正式授權需接後端。不能用 CSS 隱藏宣稱已完成存取權限控制。

## 文案規則

使用者需要的操作、錯誤、空狀態可以放程式。設計理由、閱讀方向、測試手順、動畫版本、待辦規劃與驗收報告只寫 Markdown。不得以長篇「如何試玩／如何展示」填滿空頁；不刪除實際賽制條文或必要交易確認。

## 驗收

桌機與 375px：公開頁無試看及管理控制；管理 URL 可操作；空賽程無假資料；武器圖片無破圖，未知配置不套示範；會員與指定對局交接不串號；鍵盤焦點正常，無水平溢位。
