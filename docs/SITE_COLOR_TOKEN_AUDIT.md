# 全站雙主題色彩檢查

日期：2026-10-15。色票唯一來源：`web/src/theme/lunjian.json`；使用規則：`COLOR_SYSTEM.md`。

## 統一範圍

- 全站 layout 載入同一份 theme、color-mode 與導覽樣式，包含首頁、會員、報名、裁判後台、武庫及雅戲。
- 共用 Button 新增 `primary`，使用 `accent-action-primary`、`accent-action-hover`、`text-on-action`；取消／次要操作保持中性，money／danger 保留各自語意。
- 報名、登入、註冊、會員修改、武庫確認、建立賽事、抽籤、評段、推進階段、開盤、開始回合及直播連結儲存明確指定主操作。
- 主要連結、章節標記與印章改用品牌 token，不再借用危險 token。PaperCard 的提示文字使用清楚的次要文字色，危險提示保持獨立。
- 首頁 CTA、賽程重新整理、選手資料彈窗操作，以及報名／評段／抽籤選中標記接回同一套主操作色。
- 移除會員頁強制 light 的 color-scheme，讓日期、時間與原生控制項依主題呈現。
