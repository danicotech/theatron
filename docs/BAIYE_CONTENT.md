## 本次內容要點

- 所有成員均可報名，由大會按實際 PVP 實力與經驗裁定無我、飛花、斷水、開山。
- 段位用來衡量差距及計算 BP，並非永久排名或榮譽。
- 同段 0 BP，差一／二／三段為 8／16／24 BP，只由較低段位一方取得。
- 隨機配對、BO3 先兩勝、階梯式晉級取前四。讓武配置在 BO3 前一次決定，三局固定。
- 設定在賽前公開確認並由裁判檢查；雙方全力取勝，不得放水。
- 裁判不得單憑配置強勢否決合法配置；效果實際重疊、機制產生額外限制、另一付費限制完全失效，才可要求重配。操作難度、連段或戰術價值下降不等於效果重疊。
- 未涵蓋狀況由裁判依本屆規則與讓武原則仲裁。
