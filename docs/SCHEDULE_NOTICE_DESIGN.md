# 02 懸賞雙榜 · 2026-10-28

## 最終方向
以使用者選定的「02 懸賞雙榜」取代舊賽程紙色大面板：紅、藍兩座掛布榜架，中央深木決賽榜，獨立冠軍揭榜帖；頂部換成烏鴉、木雕與燈籠的導覽。每個部件是獨立無字素材，所有標題、名稱、比分與狀態都由真實 HTML 及既有思源字體呈現。

## 桌機與手機
- 901px 起：三欄紅榜／決賽／藍榜；多輪賽程可以切換兩側來源輪次，決賽保持可見。只有資料中確定的晉級關係才畫連線。
- 900px 以下：改單欄，分輪切換；準決賽紅榜與藍榜上下閱讀，決賽另頁籤。保留字級與觸控範圍，禁止把整張桌機圖等比縮小。
- 手機導覽使用獨立窄版木紙素材；完整章節、會員與主題功能由既有可關閉目錄提供。
- 桌機背景 1920 級、榜架／名帖 960 級；手機背景 960 級、榜架／名帖 600 級。圖片依原始比例縮小，透明留白裁切，不放大低解析圖片；手機背景不隨整張長榜拉伸。
- 原始 PNG 位於 design/lunjian/lab/art/bounty-v1/_src，不發送到瀏覽器。WebP 公開檔位於 web/public/lunjian/art/bounty-v1。

## 資訊與互動
- 章節 h2 是「比賽賽程」；每榜 h3 是實際輪次；選手名與比分使用較大的正文角色，不濫加 h1。
- 場次牌、選手帖、冠軍帖保留原有點擊行為、鍵盤焦點、說明對話框及 Escape 關閉。
- 木匾 hover 用由左至右的墨線，名帖只輕提；不加水波、不反轉整張卡片、不加斜箭頭。減少動態偏好關閉位移。
- 明暗模式只在紙張／木材底層調整明度，文字獨立使用成對語意 token。未公布、輪空、即時比分、已完賽、季軍與選手操作都保留真實資料語意。
- 完整章節導航與管理編輯橋接保留。此變更未修改後端權限、正式賽事資料或資料庫結構。
