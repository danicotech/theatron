# 全站 Light／Dark 對比檢查 — 2026-10-15

保留油紙淺底與夜藍深底。這次修正共用主題與元件配色，不變更賽事、帳號、報名、注單或資料庫。

## 修正項目

- 金額、成功、危險文字各自具有 Light／Dark 色票；一般文字、提示與狀態文字以 4.5:1 為最低目標，控制項邊界以 3:1 為最低目標。
- 原生 select／option、選中選項、輸入提示、停用控制項使用成對的前景／背景。停用以虛線及不可操作狀態辨識，避免文字整體降透明度。賽程紅藍卡片保留原有美術色對。
- 修正武庫空格、裝備類型選單、星等、匯入標記、批次選取、配置文字與裝備預覽中的固定色。圖案卡片增加穩定暗罩，文字不再半透明。
- 修正表單 placeholder、裁判階段未開始文字、表格空值錯用邊框色的問題。
- 半透明賽程上的標題改用深墨，章節次要導覽取消降低文字透明度。
- 手機導覽原有同權重 CSS 規則互相覆蓋，造成會員與主題按鈕落在同一格；明確提高主題規則權重，保留分開的四欄排列。會員按鈕的 hover 狀態同時設定前景與背景，防止深字落在透明深底。

## 自動檢查

- 新增 41 項明暗色票對比及序列化檢查；涵蓋正文、次要文字、操作色、金額、成功／危險色在油紙背景、卡片與欄位上的組合，並檢查選中狀態反相配色與邊界。
- 連同登入、註冊、導覽與管理權限既有回歸：6 個檔案、59 項通過。
- 主題程式與新測試 ESLint 通過；430 個檔案的 token 檢查通過；正式版本建置及 TypeScript 檢查通過。
- 瀏覽器讀取實際 computed styles，對可解析純色及透明底進行對比檢查。七章最終複驗各 295 段文字未出現純色配對低於門檻的結果。

## 驗證界線

這是樣式與可讀性驗收，不是重新執行所有業務交易。正式賽事目前在報名階段，因此評段、抽籤、進行中、結算等尚未出現的管理畫面採共用元件／樣式審查及色票測試；未為了展開這些狀態改動真實賽事。雅戲房內未重建多人回合。原生日期／選項浮層由作業系統繪製，以實際控制項及 color-scheme／option 配色核對；不宣稱已涵蓋所有作業系統。漸層、圖片及偽元素另外目視檢查，純色掃描數字不能代表整頁無障礙認證。hover 規則經原始碼檢查，會員 hover 額外在手機驗收時實際發現並修正。
