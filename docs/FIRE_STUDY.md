# 燃燒試映（2026-10-22）

預覽：`/fire-study`。使用者認為現行發光粒子仍不自然，先提供四種候選，未替換正式序幕。

| 款式 | 比較重點 |
|---|---|
| A 薄紙細焰 | 透明細火舌、較少煙 |
| B 厚紙旺焰 | 較高火舌、較亮核心、較多黑煙 |
| C 側風捲焰 | 向右上的風偏移與較強扭動 |
| D 低焰餘燼 | 短火苗、暗紅焦化、灰煙 |

每張畫面可由實際點擊位置起火，鍵盤採中央偏下。支援一起播放、單款重播、暫停／繼續、0.5／1／1.5 倍速、進度拖曳，以及在同一次七秒播放的後半段固定燒蝕位置觀察火舌。選款只顯示本頁偏好，不修改正式動畫或儲存資料。

沿用 paperBurn 的連通燃燒抵達時間場，以紋理保存時間與預算梯度。Three.js ShaderMaterial 投射上升的連續火舌，噪聲控制燃料濃淡與扭動；煙採吸光混合，不疊加發光煙球。焦化只屬於剩餘紙面，不繪製連續外框。GSAP 控制七秒時間；這是程序式視覺近似，並非實拍素材或完整物理流體模擬。

獨立頁面才載入；不自動播放。單畫布解析度上限 640×360、像素比 1；每格捲出畫面、分頁隱藏時暫停。卸載終止 GSAP、observer、事件，釋放 Three 資源。材質非同步載入前後都有取消檢查，避免 React 重掛造成共用畫布 context 遺失。減少動態使用者可不播放，直接拖曳觀看靜態畫面。

參考：[紙張燃燒實拍](https://www.pexels.com/video/close-up-video-of-a-paper-burning-10229380/)、[Three.js 體積火焰展示](https://threejs.org/examples/webgpu_volume_fire.html)、[NIST 薄纖維素材料起火與傳播](https://www.nist.gov/publications/ignition-and-subsequent-flame-spread-over-thin-cellulosic-material)。未複製或下載第三方素材。
