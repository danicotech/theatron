# 2026-10-17 全站提示與賽程／注單入口整合

## 新流程

- 公開賽程只使用首頁 `/#schedule`。沿用既有賽程樹、手機分輪、重新整理及選手配置視窗。
- 賽程選場 → `#duel` 比武場景 → 觀局雅集彈窗，顯示該場正式 API 的盤口與投注單。
- 比武的「我的注單」開啟原頁對話框；會員選單的「我的注單」使用 `/t/[slug]/me?view=bets`，保留會員框架。
- 兩處共用 MyBets 與 listMyBets，保留 15 秒同步及下注成功即更新。沒有用本機試玩資料替代正式注單。
- 關閉對話框回到原場景與觸發按鈕；Escape 與鍵盤焦點可用。手機投注單在視窗底部展開，限制高度，保留視窗標題與關閉按鈕。
- 帳密與 Discord 登入的回程白名單納入首頁比武／賽程／報名錨點，保留 match、panel 參數，原有站外及登入循環防護不變。

## 說明分類

1. 操作教學、欄位格式、計算／玩法說明 → 關聯標題或欄位旁的藍色圈驚嘆號。
2. 當前狀態、實際數值、結果、錯誤、不可逆後果及下注確認金額 → 保留可見。
3. 混合文案分拆。例如「尚無注單」保留；選場與投注操作放到標題提示。
4. 正文規則、讓武項目的內容及選手配置屬性是核心內容，不收進提示。

已處理會員／報名武庫、註冊格式、登入後返回報名說明、投注單與注單、武庫心法／奇術／裝備／倉庫／戰力／目標及選擇視窗、小工具大廳與結果規則、後台建立賽事／抽籤／賽程管理／回合／違規／直播欄位／通行碼與讓武商店。

例：「從賠率表挑一個結果加進來。跨場可以串關，同一場只能押一腿。」保留完整內容於投注單標題提示。「尚未選擇」「已封盤」「作廢退款」、下注前確認與棄賽不可逆警語不隱藏。

## 共用規則

- 功能說明色為 accent-info：Light #185da0、Dark #91c5ff，納入主題輸出與 AA 對比測試；主品牌朱紅不變。
- 44px 點擊範圍、22px 圓圈、16px 提示內文。滑鼠移入／鍵盤聚焦顯示，手機點按顯示，移出／外點／Escape 關閉。
- 提示使用文字內容，不插入 HTML；aria-describedby 指向提示，原生 popover 避免被彈窗遮住，不支援時有回退。
- 正文與表單共用 16px；次要資料最低 14px；標題共用層級。首頁與武庫的舊 10–13px 宣告（含 font 簡寫）改成語意字級。
- 手機會員選單移除最小高度造成的列間留白。
