# 台灣運彩串關規則與本機實作對照

查核日期：2026-09-21。以下是公開規則的點數試玩改編，並非官方賠率串接或正式彩券服務。

## 官方查核

[運動彩券投注規範](https://member2.sportslottery.com.tw/zh-tw/about-us/135) 本次頁面列最新修訂為 115.6.8；重點為定義第十三點、投注方式第十六至二十一點，以及無效投注退款規定：

- 成交賠率鎖定，不隨後續報價改動。
- 最多 12 場，每場一種玩法；不同場次才能串關，可複選過關數。
- 每組以 10 元為單位，每筆總價 100–100,000 元；中獎上限 20,000,000 元，獎金四捨五入至元。
- 無效串關場次以 1 倍處理，全無效退原本金。

[官方包牌說明](https://article.sportslottery.com.tw/zh-tw/news/gm-talk/4666) 提供 3 個選項串 2 個選項，展開為 6 個組合的例子。[官方過關組合說明](https://article.sportslottery.com.tw/zh-tw/news/gm-talk/5041) 說明可同時選多種過關數及包牌。[會員 FAQ](https://article.sportslottery.com.tw/en-us/guide/159) 說明最低過關限制，以及預設拒絕任何賠率變動、可設定只接受較高賠率。

## 服務採用

| 公開機制 | 本機介面與運算 |
| --- | --- |
| 最多 12 場 | 投注單依市場分組計數；同場不同玩法替換，不能自串 |
| 多種過關數 | 勾「過 1 關／過 2 關…」，3 場選 2、3 產生 4 組 |
| 包牌 | 勾包牌後，同一玩法可選多個互斥結果；每個組合各選一項 |
| 投注單位／總價 | 將元改為試玩點數：每組 10 的倍數、整筆 100–100,000 點 |
| 固定賠率 | 新市場採管理者固定報價；「只接受較高賠率」會鎖定成交時較高值，下降仍拒絕 |
| 最低過關數 | 管理每盤可設 1–12，名次固定 1；每個組合都須符合 |
| 無效場次 | 逐組以該腿 1 倍重算；全作廢退總本金；部分退款與中獎分開顯示 |
| 中獎上限與整數 | 各組乘積保留完整精度，票內返還相加後四捨五入至整點，整票封頂 2,000 萬 |

新盤的初始 1.90 等報價是示範種子，不是台灣運彩報價。查核來源沒有提供可重現的官方開盤定價公式或本活動即時賠率，不能以人氣票數宣稱還原官方模型。

已存在的人氣盤保留原設定；點「本屆切換固定報價」會凍結目前未封盤報價，之後投票只更新支持度。已成交票的賠率不變。管理仍保留明標「舊版人氣模擬」供既有試玩回歸。

## 保留的本機限制與差異

- 原先的匿名身分、每場一票、首次 1,000 點保留；不是正式會員驗證。
- 場次開賽前封盤；沒有增開場中投注。名次盤仍限單注、不混串；四種名次與秒數玩法是百業試鋒自訂。
- 管理報價輸入 1.05–50.00 倍是既有本機範圍，不是官方賠率上限。未推導官方開盤公式，也沒有拉取官方即時賠率。
- 不複製金流、稅款、正式裁判改判或獎品履約。只用點數模擬公開的組合與派彩機制。
- 返還採整票加總後四捨五入，為本機明定的精度規則；官方公開條文明列四捨五入至元，但本次來源未詳述多組合內部逐步進位順序。
- 同筆最多 64 個選項、10,000 個組合，避免本機展開失控；介面展示前 40 組，實際整筆保存全部組合。組合結果全部可判定後一次入帳。
- 包牌最高返還按每個市場能命中的一個選項計算，不能把互斥選項全部相加。作廢時依實際各組重算，原最高返還是有效賽果的試算值。

## 相容性與驗證

正本 `web/src/features/sportsbook/tickets.ts` 使用 bigint 精確乘積與組合展開，`engine.ts` 以 `ticket` 命令在單一 IndexedDB 交易驗證全部組合、扣總點數及建單。UI 及確認摘要顯示每組本金、組合數、總本金與最高返還。

新票標記 `rules: tw-v1`、unitStake、sizes、combinations；舊票保留原始千分逐步捨去算法。正式 Hestia 的 `betSlipStore.ts` 計算函式未修改，生成 API 未修改。現有帳本、注單與會員不清除。

測試涵蓋 12／13 場邊界、過關數混選、3×2 包牌、互斥返還、總成本、最低過關、鎖價／只接受漲價、封盤、併發扣款、組合部分命中、部分／全部作廢、票內上限及整數精度。實機瀏覽器驗收狀態另見 UI_UX_VERIFICATION.md。
